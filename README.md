# Spacing-and-grid-system
Spacing and Grid System

Project Overview

This project demonstrates the use of an 8-point spacing system and a responsive 4/8/12 column grid system through a modern landing page design.

Objectives

- Understand the 8-point spacing system.
- Learn how column grids organize webpage layouts.
- Improve alignment and visual consistency.
- Apply responsive design principles.

Design Specifications

Spacing System

8px, 16px, 24px, 32px, 40px, 48px and 64px.

Grid System

- Desktop: 12 columns
- Tablet: 8 columns
- Mobile: 4 columns

Tools Used

- Figma
- Figma AI

What I Learned

I learned how consistent spacing and grid layouts improve readability, alignment and the overall appearance of a website.
